    vx-route

    vx-route | VxRoute

    A vx-route defines an individual route path. A route must be defined as a direct child of a VxRouter element.

    Parsing of the route is done by the path-to-regexp library from npmjs and any parameters extracted stored in the route's paramters property.

    Examples

        <vx-route path="/home">
        This is the content of the home page
    </vx-route>
    The parameter is saved in the route's parameters property and can be interrogated by child elements. 
        <vx-route path="/products/:id">
        <my-products-page></my-products-page>
    </vx-route>
    The subroute flag indicate a routing node. A child <vx-router element would be responsible for processing further path fragments. The child router does not have to be a direct child.

        <vx-route path="/products" subroute>
        <my-products-page></my-products-page>
    </vx-route>
    Instead of placing content in the default slot, a component can be named. The component element is created and added to the DOM by the route. When the route is no longer active, the element is removed from the DOM. 
        <vx-route path="/products" component="my-products-page" subroute>
    </vx-route>

    Attributes

    path

    Type string
    Default-

    The path for this route relative to any parent routes. See path-to-regexp on npmjs.com for an explanation of the path syntax

    subroute

    Type boolean
    Defaultfalse

    Identifies the route as a subroute.

    component

    Type string
    Defaultnull

    This component will be created and added to the DOM instead of rendering the slotted elements.

    active

    Type boolean
    Defaultfalse

    Indicates this path is active. The attribute is automatically set/reset by the parent vx-router component.

    Properties

    customTemplate

    Type TemplateResult
    DefaultTemplateResult | () => TemplateResult

    An alternative template to use where using slotted elements is not suitable. The value of this property should be set during a vx-connected or vx-activated event.

    componentRef

    Type HtmlElement
    Defaultundefined

    A reference to the component created when the component attribute was specified

    parameters

    Type object
    Default{}

    The parameters extracted from the URL by the route

    Events

    Event Description
    vx-connected Called when the route is connected to the DOM.
    vx-activate Called when the route is about to be activated.
    vx-activated Called when the route has been activated.
    vx-deactivate Called when the route is about to be deactivated.
    vx-deactivated Called when the route has been deactivated.

    Slots

    Name Description
    (default) Content to be displayed when the route is active and component property is not set.
